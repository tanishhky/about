## Overview

This repository houses the source code for my deployed personal portfolio website. It acts as a comprehensive resume, project gallery, and central hub for my professional identity online. 

## Structure
- `index.html`: The central document containing the semantic layout of the portfolio sections.
- `css/`: Responsive styling parameters enforcing a robust grid and consistent typography across desktop and mobile devices.
- `js/`: Scripts managing interactive animations, scrolling behaviors, and dynamic elements.
- `assets/`: Contains project screenshots, icons, and personal branding elements.

## Deployment
This repository is configured to be deployed via platforms like GitHub Pages, Vercel, or Netlify with zero build-steps—serving static frontend assets efficiently to global users.
