# tanishkyadav.me

Personal research site of Tanishk Yadav (MS Financial Engineering, NYU Tandon, May 2027). Static HTML on Vercel, generated by a small Python script with no dependencies.

## Structure

| Path | What it is |
|---|---|
| `/` | Positioning, the latest paper, research, thesis, systems, how I work, teaching, contact |
| `/research` and `/research/<slug>` | One landing page per paper: status, abstract, key results, figures, limits, hosted PDF, code, BibTeX, Google Scholar meta tags |
| `/thesis` | MS thesis (description only; results appear after they pass the thesis quality gate) |
| `/cv` | Full record behind the one-page resume |
| `/writing` | Posts and teardowns |
| `/papers/*.pdf` | Author versions of each paper |
| `/Tanishk_Yadav_Resume.pdf` | Current one-page resume (copied from the SecondBrain master) |

Old URLs redirect (`/credentials`, `/resumes/*`); see `vercel.json`.

## Editing

All content lives in `tools/content.py`. After editing it:

```bash
python3 tools/build.py   # regenerates every HTML page, sitemap.xml, robots.txt, vercel.json
python3 tools/og.py      # re-renders social preview images (needs Google Chrome)
```

Then commit the generated files; Vercel serves the repository as-is.

Content rules: status words are exact ("Journal submission", "SSRN preprint", "Working paper"; never "published"), thesis entries stay description-only, no GPA or GRE, and no em or en dashes (the build fails if one appears).

## Design

Paper-and-ink palette with an NYU violet accent, Newsreader for headings, Inter for text, JetBrains Mono for numbers. Light and dark themes, WCAG-AA contrast, keyboard navigation, and every page works without JavaScript.
